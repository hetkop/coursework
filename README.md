# Мебельный магазин — мобильное приложение (Android, Kotlin)

Стек: Kotlin, Jetpack Compose (Material 3), SQLite (чистый SQL, без ORM), MVVM.

## Запуск
1. Android Studio (Koala 2024.1 или новее) -> File -> Open -> папка проекта.
2. Дождаться Gradle Sync (нужен интернет, JDK 17 входит в Android Studio).
3. Запустить на эмуляторе или устройстве (Android 8.0+, minSdk 26).

## Структура
- data/Schema.kt — SQL: 11 таблиц, индексы, 6 триггеров, начальные данные
- data/Db.kt — SQLiteOpenHelper (создание БД, включение внешних ключей)
- data/Repository.kt — SQL-запросы, транзакции, перевод ошибок СУБД в сообщения
- ui/ — экраны Compose, ViewModel, общие компоненты

## Роли
- Администратор: товары, заказы, клиенты, поставки, справочники, отчёты
- Руководитель: только отчёты (заказы за период, популярные товары, остатки)

## Целостность данных
- Транзакции: оформление заказа, регистрация и удаление поставки, удаление заказа
- Триггеры: контроль остатка, списание/возврат/оприходование товара
- Внешние ключи и CHECK-ограничения блокируют некорректное удаление и значения
